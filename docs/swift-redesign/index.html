Copier Swift Redesign

Screens for the native macOS rewrite. Each screen follows the system appearance. Open a screen on its own and add ?dark or ?light to force one. Background and decisions: README.md.

1 · Waiting for card

Idle state. The scan starts on its own when a card is inserted.

2 · Review, folder per day

One row per day with its folder field. The open day lists every file on the card, including the ones Copier leaves out by default.

2b · Choosing an existing folder

The arrow in the folder field lists the folders that already exist at the destination.

2c · Review, one folder

Everything goes into a single new or existing folder.
